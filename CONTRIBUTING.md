# Contributing

This repository is mainly a catalog and examples hub for my Engineering Toolkit.

Good changes here include:

- Catalog updates
- Documentation fixes
- Link corrections
- Composition examples
- General improvements to the hub

Implementation changes should usually happen in the owning tool repository.

When adding or updating a catalog entry, include the owning repository if it exists. If a link is only a placeholder, label it clearly. Examples should show how tools fit together instead of copying implementation code into this repository.
